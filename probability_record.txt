上涨概率
规则在看测试窗之前写死。测试窗只用来决定是否启用分档概率，不回写概率本身。
持有期 20 来自已经完成的有效性检验，本脚本不比较其他持有期。

冻结规则
  训练截止日（卖出日不晚于此日）: 2023-12-31
  持有期: 20 个交易日。信号日收盘之后，次日开盘买入，到期开盘卖出。
  分档数: 5。第 5 档是得分最高的一档。
  启用所需的最少调仓日: 10
  Newey-West t 门槛: 2.0
  上涨: 能成交且毛收益 > 0。毛收益为 0 不算上涨。
  未成交（涨停开盘、跌停开盘、停牌、复权断裂）不进入概率，也不记成下跌。
  基准概率: 训练窗调仓日上涨频率的平均。
  条件概率: 训练窗各档调仓日上涨频率的平均。
  启用条件模型: 第5档频率 >= 第1档，测试窗 Brier 更低，且 Brier 差的 NW t > 2。
  不启用时的结论句: 个股之间没有可区分的上涨概率
  启用时的结论句: 上涨概率按训练窗分档使用，名单只含得分最高的一档
  收益检验的结论仍以 validity_record.txt 为准。本脚本不改那句话。

  PASS 空仓建仓只付买入佣金

  PASS 相关 0.85 时丢掉 |t| 较小的趋势
  PASS 相关 0.40 时两个都留
  PASS 权重只留给 |t|>=2 的因子且保留符号
  PASS 隔离带不进训练窗也不进测试窗
  PASS 合成序列能生成信号
  PASS 10% 开盘被标成涨停且没有收益
  PASS 其余平盘有成交且毛收益为 0
  PASS 单名净收益与整段公式一致
  PASS 方向对、Brier 更低且 t>2 时启用
  PASS 高分档频率更低时不启用
  PASS Brier 没有更低时不启用
  PASS t 不超过 2 时不启用
  PASS 调仓日不足时不启用
  PASS 构造样本高分档上涨频率为 1
  PASS 构造样本低分档上涨频率为 0
